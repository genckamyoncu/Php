# React + wagmi NFT Minter

RainbowKit ve wagmi kullanarak Base üzerindeki NFT kontratınıza mint işlemi gönderebilen hafif bir arayüz.

## Kurulum

```bash
npm install
npm run dev
```

`.env` dosyası ile Vite runtime değişkeni tanımlayın:

```
VITE_NFT_CONTRACT_ADDRESS=0x...
```

Varsayılan ağlar Base Mainnet ve Base Sepolia'dır. ProjectId olarak örnek bir değer kullanılmıştır; kendi WalletConnect ID'niz ile değiştirebilirsiniz.
