# Base Network Mini App Collection

Bu depo, Base geliştirici airdrop programı için kullanılabilecek on farklı mini uygulama ve betik örneği içerir. Hepsi açık kaynaklıdır ve popüler dillerde yazılmıştır; PHP kullanılmamıştır.

Her proje, Base ağında deneme dağıtımları yapabilmeniz veya kodu kendi ihtiyaçlarınıza göre uyarlayabilmeniz için talimatlar ve örnekler içerir. Ayrıntılar için `apps/` klasöründeki alt dizinlere bakın.

## İçerik

1. Hardhat tabanlı ERC-20 tokeni
2. Hardhat tabanlı ERC-721 NFT koleksiyonu
3. Foundry ile anlık akış ödemeleri sözleşmesi
4. Foundry ile kimlik doğrulamalı erişim kontrolü
5. Python (web3.py) ile Base Bridge izleme betiği
6. Node.js (ethers.js) ile Base üzerinde token gönderme
7. React + wagmi + viem ile Base NFT mint arayüzü
8. Go (go-ethereum) ile Base cüzdan bakiyesi okuma
9. Rust (ethers-rs) ile Base RPC sağlık denetleyicisi
10. Subgraph şablonu ile zincir üstü veri indeksleme başlangıcı

Her proje kendi `README.md` dosyasında kurulum ve kullanım adımlarını listeler.
